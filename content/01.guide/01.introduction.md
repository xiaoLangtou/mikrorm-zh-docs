## 简介

MikroORM 是一个基于 Data Mapper（数据映射器）、Unit of Work（工作单元）和 Identity Map（身份映射）模式的 TypeScript ORM，用于 Node.js 开发。在本指南中，你将了解这些术语的含义，学习如何搭建一个简单的 API 项目、如何进行测试，以及更多内容。

_MikroORM is a TypeScript ORM for Node.js based on Data Mapper, Unit of Work, and Identity Map patterns. In this guide, you will learn what those words mean, how to set up a simple API project, how to test it, and many more._

本入门指南采用循序渐进的教程形式编写，配有可运行的 StackBlitz 示例和一个[包含最终项目的 GitHub 仓库](https://github.com/mikro-orm/guide)。它将向你展示如何从零开始创建一个生产就绪的应用程序，直到构建一个可以部署到任何地方的 Docker 镜像。

_This Getting Started Guide was written as a step-by-step tutorial, accompanied by working StackBlitz examples and a [GitHub repository with the final project](https://github.com/mikro-orm/guide). It will show you how to create a production-ready application from scratch, all the way down to a docker image you can deploy wherever you want._

要预览我们将要构建的最终项目，请尝试克隆 [`mikro-orm/guide` GitHub 项目](https://github.com/mikro-orm/guide)。

_To take a peek at the final project we will be building, try cloning the [`mikro-orm/guide` GitHub project](https://github.com/mikro-orm/guide)._

```bash
git clone https://github.com/mikro-orm/guide.git
```

:::info 提示 / Info
本指南专注于使用“代码优先”的方式开发应用程序，但 MikroORM 也可以使用“模式优先”的方式。查看[模式优先指南](../schema-first-guide.md)了解更多详情。

_This guide focuses on "code first" approach to developing the application, but MikroORM can also be used with a "schema first" approach. Check out [the "schema first" guide](../schema-first-guide.md) for more details on that._
:::

## MikroORM Monorepo

ORM 由多个包组成，我们将使用的重要包有：

_The ORM consists of several packages, the important ones we will be using:_

- `@mikro-orm/core`：包含 ORM 代码的主包

  _The main package with the ORM code_

- `@mikro-orm/cli`：CLI 包，需要本地安装

  _The CLI package, needs to be installed locally_

- `@mikro-orm/sqlite`：SQLite 驱动包（你也可以使用其他驱动）

  _The sqlite driver package (you can use a different driver too)_

- `@mikro-orm/reflection`：通过 ts-morph 反射启用 DRY（不重复）的 Entity 定义

  _To enable DRY entities with ts-morph reflection_

- `@mikro-orm/migrations`：用于管理数据库迁移的包

  _Package for managing schema migrations_

- `@mikro-orm/seeder`：用于向数据库填充测试数据的包

  _Package for seeding the database with testing data_

`core` 和驱动包是必需的，列表中的其余部分是可选的，如果你愿意，可以作为开发依赖。我们将使用 `sqlite` 驱动，主要是为了简单起见，因为它不需要任何额外的设置，并且提供了一个方便的内存数据库，我们将在测试中使用它。

_The `core` and driver packages are required, the rest of this list is optional and can be a dev dependency if you wish. We will use the `sqlite` driver, mainly for simplicity, as it does not require any additional setup and offers a handy in-memory database, which we will use in the tests._

> 还有更多的包，其中一些位于 `mikro-orm/mikro-orm` monorepo 之外，例如 `@mikro-orm/nestjs` 或 `@mikro-orm/sql-highlighter`——与 monorepo 中的包不同，这些包通常有不同的版本线。
>
> _There are more packages, some also live outside the `mikro-orm/mikro-orm` monorepo, such as the `@mikro-orm/nestjs` or `@mikro-orm/sql-highlighter` - unlike the ones from the monorepo, those usually have different versioning line._

## 我们要构建什么？

我们已经提到了将使用的技术，现在来详细介绍一下项目。这将是一个简单的博客 API，具有身份认证、发布和评论功能。为此，我们将使用四个常规 Entity：`User`、`Article`、`Comment` 和 `Tag`。之后，我们还将添加一个 Entity，即 `ArticleListing`，这是一个由 SQL 表达式而非数据库表表示的虚拟 Entity。

_We already mentioned what technologies will be used, and now more about the project. It will be a simple API for a blog, with authentication, publishing, and commenting. For that, we will use four regular entities: `User`, `Article`, `Comment`, and `Tag`. Later on, we will add one more entity, `ArticleListing`, a virtual entity represented by an SQL expression rather than a database table._

API 路由说明：

_And the API routes description:_

| 方法 / Method | URL | 描述 / Description |
|---|---|---|
| `POST` | `/user/sign-up` | 注册新用户 / Register new user |
| `POST` | `/user/sign-in` | 登录现有用户 / Login existing user |
| `GET` | `/user/profile` | 获取完整个人资料 / Get your full profile info |
| `PATCH` | `/user/profile` | 修改个人资料 / Modify your profile |
| `POST` | `/article` | 创建新文章 / Create new article |
| `GET` | `/article` | 列出现有文章 / List existing articles |
| `GET` | `/article/:slug` | 获取文章详情 / Get article detail |
| `PATCH` | `/article/:slug` | 修改现有文章 / Modify existing article |
| `DELETE` | `/article/:slug` | 删除现有文章 / Delete existing article |
| `POST` | `/article/:slug/comment` | 为现有文章发表评论 / Post comment for existing article |

代码将被组织成独立的模块：`user`、`article` 和 `common`（用于共享辅助函数）。

_The code will be structured into self-contained modules: `user`, `article`, and `common` (for shared helpers)._

应用程序将使用 Node.js 20、TypeScript 5.2，我们将使用启用了 ECMAScript modules 的现代技术栈来构建它。

_The app will be using Node.js 20, TypeScript 5.2, and we will build it using a modern stack with ECMAScript modules enabled._
